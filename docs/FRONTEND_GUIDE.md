# 프론트엔드 팀 전달 - 백엔드 서버 연동 안내

## 1. API 서버 주소

```
http://1.201.116.47:8080
```

가비아 클라우드 서버에 배포되어 있고, `main` 브랜치에 백엔드 변경사항이 머지될
때마다 자동으로 재배포됩니다. 즉 별도 공지 없어도 최신 API가 반영돼 있다고
보시면 됩니다 (배포에 1~2분 정도 걸릴 수 있음).

## 2. API 문서 (Swagger)

```
http://1.201.116.47:8080/swagger-ui/index.html
```

전체 API 목록, 요청/응답 스키마를 여기서 바로 확인하고 브라우저에서 직접
호출 테스트도 가능합니다.

## 3. 인증 방식 (JWT)

1. `POST /auth/signup` — 회원가입
2. `POST /auth/login` — 로그인, 응답으로 JWT 토큰(`accessToken` 등) 반환
3. 이후 인증이 필요한 API 호출 시 헤더에 아래처럼 담아서 요청

```
Authorization: Bearer {로그인 응답으로 받은 토큰}
```

`/auth/**`, `/swagger-ui/**`, `/uploads/**` 경로는 토큰 없이도 접근 가능하고,
그 외 API는 전부 토큰이 필요합니다.

## 4. CORS 허용 목록

현재 백엔드가 CORS를 허용하는 origin은 아래와 같습니다.
```
http://localhost:3000
http://localhost:5173
https://welli-fe-a.vercel.app
```
로컬 개발 포트를 위 목록 외의 것으로 쓰시거나, 배포 도메인이 추가로
생기면 백엔드 팀에 알려주시면 허용 목록에 추가해드립니다.

## 5. 파일 업로드/정적 리소스

업로드된 이미지 등은 아래 경로로 접근 가능합니다.
```
http://1.201.116.47:8080/uploads/{파일명}
```

## 6. 백엔드 HTTPS 전환 진행 중

프론트가 `https://welli-fe-a.vercel.app`로 배포되어, 지금의 HTTP 백엔드
(`http://1.201.116.47:8080`)를 그대로 호출하면 브라우저 Mixed Content
정책에 막힐 수 있습니다. 백엔드에 도메인(`api.hellofriend-eulji.site`)을
연결하고 HTTPS로 전환하는 작업을 진행 중이며, **완료되면 API 주소가
`https://api.hellofriend-eulji.site`로 바뀝니다.** 전환 완료 시점은 백엔드
팀에서 다시 공지드릴 예정이니, 그때 프론트의 API base URL을 새 주소로
교체해주세요. (전환 전까지는 기존 `http://1.201.116.47:8080` 그대로
사용하시면 됩니다.)

공유해주세요. 서버 로그로 원인 확인 가능합니다.
